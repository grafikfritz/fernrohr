# Fernrohr · Test

Prototyp für ein Fernrohr vor einem Solarpark: Handy ins Cardboard oder als Einzelbild vor sich halten und sich rundum im 360°-Panorama der fiktiven Kunstinstallation »Saison« umschauen. Antippen richtet den Blick wieder auf die Piste aus. Ansichten: VR (Cardboard), Fernrohr mit zwei Kreisen (Cardboard), Einzelbild, Einzelbild rund.

Öffnen am Handy: https://grafikfritz.github.io/fernrohr/

- Das Panorama lädt in voller Auflösung von fal. Fällt das aus, springt `bilder/pano-vorschau.webp` ein (unscharf). Eine eigene Datei `bilder/pano.jpg` hat Vorrang.
- Parameter des Panoramas (Naht, Horizonthöhe, Startrichtung, Himmels- und Bodenfarbe) stehen oben im Skript unter `PANO`.
- `?debug` an die Adresse hängen zeigt Sensorwerte.

Design Fiction, Masterarbeit Angewandte Designforschung, HM FK12.
